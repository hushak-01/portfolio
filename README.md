# 个人作品集

面向 AI 产品经理 / 产品经理方向的案例展示，收录 3 个 PoC 作品，重点呈现问题分析、产品方案、业务流程和可交互 Demo。

## 在线 Demo

- [个人作品集主页](https://portfolio-five-ecru-18.vercel.app/)
- [GitHub 仓库](https://github.com/hushak-01/portfolio)

## 案例目录

1. **废旧回收量价预测系统**  
   基于时间序列和数据分析思路，展示采购价格、市场价格与回收量预测的业务分析方案。

2. **AI 视觉核验与自动化台账系统**  
   围绕工业废料回收场景，展示图片核验、结构化结果和台账流程的产品化设计。

3. **AI 商业风控与出海合规解析**  
   展示 B 端回款风控、跨语言文献解析和涉外合规辅助的产品方案。

## 仓库内容

- `Portfolio/index.html`：量价预测案例
- `Portfolio/page2.html`：视觉核验案例
- `Portfolio/page3.html`：商业风控与合规案例
- `Portfolio/*.png`：案例配图

## Demo 说明

本仓库主要用于作品展示，当前以 HTML 静态页面、预生成图表和示例数据为主：

- 页面中的图表、JSON 和交互结果用于演示产品思路，不代表线上业务指标。
- 当前仓库不包含完整的 Python 后端、数据库或生产 API 服务。
- 页面中的业务案例已按作品展示用途进行匿名化处理，请勿将其理解为对具体客户或公司的披露。
- 本仓库不应提交 API Key、密码、客户资料、合同或其他敏感信息。
